# Changelog

## 1.4.2 — 2026-11-10
- Corrige le prompt de nouvelle app resté vide après une mise à jour : le navigateur gardait l'ancien code en cache
- Affiche un message clair si un modèle de prompt ne peut pas être lu

## 1.4.1 — 2026-11-10
- Le prompt de nouvelle app est lu dans le design system, enrichi des pièges déjà rencontrés (CLAUDE.md, données, dépendances, vérifications)

## 1.4.0 — 2026-11-10
- Ajoute l'onglet Créer : un formulaire qui écrit le prompt de démarrage d'un nouveau jeu (repris de game-system) ou d'une nouvelle app
- Les inspirations du jeu et les apps modèles se choisissent dans une fenêtre au premier plan, avec tirage au sort pour les jeux

## 1.3.0 — 2026-10-31
- Permet de modifier les étoiles d'un projet en cliquant dessus sur sa fiche
- Ajoute dans les Réglages la publication des étoiles modifiées (jeton GitHub gardé dans le navigateur)

## 1.2.0 — 2026-10-31
- Ajoute le tri par étoiles (importance, primaires d'abord) et par date
- Ajoute l'affichage en liste compacte, en plus des cartes
- Ajoute la version, les dernières modifications et la roadmap sur les fiches quand elles existent
- Corrige les descriptions répétées sur les fiches

## 1.1.0 — 2026-10-29
- Ajoute les captures des projets sur les cartes et les fiches
- Ajoute automatiquement les nouveaux dépôts au hub (toutes les 6 heures, avec capture de la démo)

## 1.0.1 — 2026-10-29
